# RedInk

RedInk is a Manifest V3 Chrome extension that listens to audio from a browser tab and displays short, AI-generated claim assessments in a newspaper-style sidebar. It is designed for people following speeches, interviews, and debates who want to notice claims that may need closer checking without switching tabs.

## How it works

1. Start a session from the extension popup while viewing media in a browser tab.
2. The extension captures tab audio and streams it to Deepgram for transcription.
3. The service worker batches transcript segments and sends them to a Featherless-hosted language model.
4. RedInk shows each extracted claim, speaker label, verdict, and short explanation in a sidebar isolated with Shadow DOM.

Verdict labels include confirmed, mostly true, misleading, false, and unverified.

## Setup

1. Load this folder as an unpacked extension from `chrome://extensions`.
2. Open the RedInk popup and enter your own Deepgram and Featherless API keys, then save them.
3. Open a speech, interview, debate, or other media tab and start a session.

The extension stores keys in Chrome extension local storage and uses them to call the configured providers. Do not commit personal API keys to source control.

## Limits

Verdicts are generated by an AI model and can be wrong. RedInk does not currently attach source citations to its assessments. Treat its output as a prompt to verify claims against reliable sources, not as proof that a statement is true or false.
